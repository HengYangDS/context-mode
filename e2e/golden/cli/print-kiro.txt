Manual setup for kiro. Put this in <HOME>/.kiro/settings/mcp.json
(If the folder or file is missing, create it. If the file exists, add the context-mode entry
and keep the rest. These paths are for this machine.)

{
  "mcpServers": {
    "context-mode": {
      "command": "<NODE>",
      "args": [
        "<PKG>/server.mjs",
        "--agent",
        "kiro"
      ]
    }
  }
}

Then restart the agent and check it: context-mode doctor --agents kiro
