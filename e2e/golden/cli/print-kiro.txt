Manual setup for kiro. Put this in <HOME>/.kiro/settings/mcp.json
(If the folder or file is missing, create it. If the file exists, add the context-mode entry
and keep the rest. These paths are for this machine.)

{
  "mcpServers": {
    "context-mode": {
      "command": "<NODE>",
      "args": [
        "<PKG>/server.mjs",
        "--agent",
        "kiro"
      ]
    }
  }
}

Hooks: put this in <HOME>/.kiro/hooks/context-mode.json (keep your own entries):

{
  "version": "v1",
  "hooks": [
    {
      "name": "context-mode-SessionStart",
      "trigger": "SessionStart",
      "action": {
        "type": "command",
        "command": "\"<NODE>\" \"<PKG>/hook.mjs\" --agent kiro"
      },
      "timeout": 5,
      "enabled": true
    },
    {
      "name": "context-mode-UserPromptSubmit",
      "trigger": "UserPromptSubmit",
      "action": {
        "type": "command",
        "command": "\"<NODE>\" \"<PKG>/hook.mjs\" --agent kiro"
      },
      "timeout": 5,
      "enabled": true
    },
    {
      "name": "context-mode-PreToolUse",
      "trigger": "PreToolUse",
      "action": {
        "type": "command",
        "command": "\"<NODE>\" \"<PKG>/hook.mjs\" --agent kiro"
      },
      "timeout": 5,
      "enabled": true,
      "matcher": "@mcp"
    },
    {
      "name": "context-mode-PostToolUse",
      "trigger": "PostToolUse",
      "action": {
        "type": "command",
        "command": "\"<NODE>\" \"<PKG>/hook.mjs\" --agent kiro"
      },
      "timeout": 5,
      "enabled": true,
      "matcher": "@mcp"
    }
  ]
}

Skill: put this in <HOME>/.kiro/skills/ctx-doctor/SKILL.md:

---
name: ctx-doctor
description: Check that context-mode is installed and working, as a table.
disable-model-invocation: true
---
Call the mcp_context-mode_ctx_doctor tool and show its table to the user unchanged. If a row failed, list the fixes it names, in order.

Skill: put this in <HOME>/.kiro/skills/ctx-stats/SKILL.md:

---
name: ctx-stats
description: Show how much context context-mode saved, as a table.
disable-model-invocation: true
---
Call the mcp_context-mode_ctx_stats tool and show its table to the user unchanged. Add one sentence under the table that names the largest saving.

Skill: put this in <HOME>/.kiro/skills/ctx-upgrade/SKILL.md:

---
name: ctx-upgrade
description: Update context-mode to the latest release.
disable-model-invocation: true
---
Call the mcp_context-mode_ctx_upgrade tool and show its table to the user. Then call mcp_context-mode_ctx_doctor and show its table. If a restart is needed, say so in one sentence.

Then restart the agent and check it: context-mode doctor --agents kiro
